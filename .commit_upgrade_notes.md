# Nexo AI — GitHub Commit Flow Upgrade (v3.3.0)

## Plan Summary (from user's pasted_content_2.txt)
Upgrade GitHub commit flow from sequential single-file Contents API loop to atomic multi-file commits via GitHub Git Data API.

### Key changes needed:
1. **Atomic Multi-file Commits** — Git Data API (create blob → build tree → create commit → update ref)
2. **Branch/PR Mode** — "Commit to main" or "Open as PR" (create branch `nexo-craft/<timestamp>`, push, open PR)
3. **Safer Diff Validation** — Verify every diff against current file content before committing; abort if stale
4. **Progress UI** — "Creating blobs...", "Building tree...", "Updating branch..." steps + commit/PR links + retry
5. **Security** — `repo` scope in OAuth callback, token never exposed

### Files to modify:

### Current commit route structure (route.ts):

- Fetches token from `github_connections` table (access_token, selected_repo)
- `CommitFile` interface: { filePath, content, type: "editing"|"creating"|"deleting" }
- Currently: sequential loop over files, PUT/DELETE per file
- Returns: { success: boolean, results: [{ filePath, success, error }] }

### FileAction type (from craftParser):
- type: "reading"|"editing"|"creating"|"deleting"

### Git Data API flow:
1. GET /repos/{owner}/{repo}/branches/{branch} → get commit SHA and tree SHA
2. For each new/modified file: POST /repos/{owner}/{repo}/git/blobs → get blob SHA
3. GET /repos/{owner}/{repo}/git/trees/{tree_sha}?recursive=1 → get base tree
4. POST /repos/{owner}/{repo}/git/trees → create new tree (add blobs, remove deleted)
5. POST /repos/{owner}/{repo}/git/commits → create commit (tree + parent SHA)
6. PATCH /repos/{owner}/{repo}/git/refs/heads/{branch} → update branch to new commit

### PR flow:
1. Create branch from main: POST /repos/{owner}/{repo}/git/refs {ref: "refs/heads/nexo-craft/<ts>", sha: mainCommitSha}
2. Push commit to new branch
3. POST /repos/{owner}/{repo}/pulls {head: branchName, base: "main", title, body}
